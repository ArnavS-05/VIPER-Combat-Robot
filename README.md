# VIPER — Owl Robotics

1-lb Plastic Antweight team repository containing six original native SolidWorks parts.

## Files and version status

- `VIPER_Chassis_Optimized_MODIFIED_F.SLDPRT` — **presumed latest chassis**, based only on its filename; the team should confirm before editing or printing.
- `VIPER_Chassis_Optimized_MODIFIED.SLDPRT` — alternate chassis version.
- `VIPER_Chassis_Optimized(1).SLDPRT` — alternate chassis version.
- `VIPER_Lid.SLDPRT`
- `T1.SLDPRT`
- `T2.SLDPRT`

Original filenames and file contents are preserved. Version order, fit, and print readiness have not been independently validated.

## Team collaboration

1. The owner invites teammates through **Settings → Collaborators → Add people**. Accept the invitation using the intended GitHub account. This repository is public: anyone with the link can view and download the files. A collaborator invitation is required to push changes directly.
2. Clone with GitHub Desktop, or use **Code → Download ZIP** for a snapshot. Open the native `.SLDPRT` files in a compatible SolidWorks version.
3. Pull the latest changes before editing. Agree on who edits each part: SolidWorks files are binary and cannot be merged like text.
4. Make changes on a branch, commit with a short description, and open a pull request for teammate review before merging into `main`.
5. Preserve earlier versions until the team agrees which chassis is current. If an assembly is added later, use SolidWorks Pack and Go to include its referenced parts.
